# Portfolio Site

This is a modern portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Responsive design that works on all devices
- Smooth animations using Framer Motion
- Interactive background with tsparticles
- Testimonial and work sliders using Swiper

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- tsparticles
- Swiper

## Project Structure

- `/components` - Reusable UI components
- `/pages` - Application routes
- `/public` - Static assets
- `/styles` - Global styles and Tailwind configuration
- `/types` - TypeScript type definitions

## Customization

Edit `tailwind.config.js` to customize colors, fonts, and other design elements.
Replace content in the page components to personalize your portfolio.
